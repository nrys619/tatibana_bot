# はじめかた (完全初心者向け)

プログラミングも投資もはじめての人向けに、Macでこのボットを動かすまでの手順を説明します。
**1文字でも違うと動かないので、コマンドはコピー&ペーストしてください。**

## このボットは何をするの?

「日本株のデイトレを手伝うロボット」です。中身は4人のチームだと思ってください。

| 担当 | 仕事 |
|---|---|
| 選ぶ係 (AI) | 毎晩、過去のデータから「明日よく動きそうな株」を数銘柄選ぶ |
| 読む係 (AI) | 朝、会社の発表 (決算など) を読んで「良いニュースか悪いニュースか」を判定 |
| 見る係 | 昼、選ばれた株の「買いたい人と売りたい人の勢い」を毎秒見張り、チャンスで売買の合図を出す |
| 止める係 | 危ない日はロボットの使うお金を減らし、負けが続いたらその日は強制終了 |

## 大事な安全装置 (先に知っておくこと)

- **デモ口座** = ゲームのお金で取引する練習用の口座。今持っている鍵はデモ用なので、
  何をしても本物のお金は1円も動きません。
- **paperモード** = さらにその上の安全装置。注文自体を送らず「買ったつもり」を
  ノートに記録するだけ。**最初は必ずこれで動かします。**
- `secrets/` に入れる2つのファイル (認証IDと秘密鍵) は家の鍵と同じです。
  人に送らない・SNSに貼らない・このフォルダから動かさない。

## セットアップ (最初の1回だけ、約15分)

### 1. ターミナルを開く

Macの「ターミナル」というアプリを使います。
Launchpad → 「その他」 → 「ターミナル」。黒い画面が出たらOK。

### 2. 道具がそろっているか確認

下の2行を1行ずつ貼り付けてEnter:

```bash
python3 --version
git --version
```

- `Python 3.10` 以上の数字が出ればOK (3.9以下なら https://www.python.org/downloads/ から最新を入れる)
- gitで「コマンドライン・デベロッパツールをインストールしますか?」と聞かれたら「インストール」を押して待つ

### 3. ロボットのプログラムを自分のMacに持ってくる

```bash
cd ~
git clone https://github.com/nrys619/tatibana_bot.git
cd tatibana_bot
git checkout claude/ai-trading-bot-markets-sodkls
```

(「GitHubに置いてあるプログラム一式をコピーして、その中に入る」という意味です)

### 4. ロボットの部品を組み立てる

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

2〜3分かかります。`(.venv)` が行の先頭に付くようになれば成功。
(これは「このプロジェクト専用の道具箱を作って、必要な部品を全部入れる」作業です)

### 5. 鍵と設定ファイルを置く

```bash
mkdir -p secrets
cp ~/Downloads/e_api_authid.txt secrets/
cp ~/Downloads/e_api_private_key.pem secrets/
cp .env.example .env
cp config/config.example.yaml config/config.yaml
```

ダウンロードした4ファイルのうち使うのは上の2つだけです。
残り (public_key の2つ) は立花証券に登録済みのものなので、そのまま置いておけばOK。

設定はデモ口座用になっているので、**何も書き換えなくて大丈夫です。**

### 6. 動作チェック

```bash
pytest
```

最後に `35 passed` のように緑で出れば、組み立て成功です。

## 毎日の使い方 (3コマンド)

※ 2回目以降にターミナルを開いたときは、最初にこれを実行してから:

```bash
cd ~/tatibana_bot && source .venv/bin/activate
```

### 夜 (何時でもOK): 明日の銘柄を選ばせる

```bash
python scripts/nightly.py --train
```

過去の株価データを集めて、AIが「明日動きそうな株ランキング」を作ります。

### 朝 8時ごろ (省略OK): ニュースを読ませる

```bash
python scripts/premarket.py
```

※ これだけはAnthropicのAPIキー (有料、1回数十円〜) が必要です。
`.env` の `ANTHROPIC_API_KEY` に設定します。**最初のうちは飛ばしてOK。**

### 平日 9:00〜15:30: ロボットを見張りにつかせる

```bash
python scripts/run_live.py --mode paper
```

画面に「買ったつもり」「売ったつもり」のログが流れます。
止めたいときは `Ctrl + C` (controlキーを押しながらC)。

### 結果を見る

取引の記録は `data/trades.sqlite3` に、ログは画面に残ります。
「もし本当に売買していたら勝てていたか?」をここで確認します。

## 卒業までの道のり

1. **いま**: paperモードで数週間動かして記録を貯める
2. 記録を見て「勝てそうか」を判断 (勝てないならパラメータやロジックを直す)
3. デモ口座 + liveモードで実際の注文の流れを確認
4. それでも勝てていたら、初めて本番口座 + 少額を検討

焦らないこと。ほとんどのボットは2で作り直しになります。それが普通です。

## うまくいかないとき

- エラー文をそのままコピーして、Claudeに貼り付けて聞いてください
- よくあるもの:
  - `command not found: python3` → Pythonが入っていない (手順2)
  - `No such file or directory` → いる場所が違う。`cd ~/tatibana_bot` してから再実行
  - `environment variable ... is not set` → 手順5の `.env` 作成を忘れている
